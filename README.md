# Iris Dataset Analysis Project

## Overview
This project provides an end-to-end data exploration and analysis of the Iris dataset using Python and Pandas.

## Project Structure
- `data/`: Contains the raw dataset (`iris.csv`).
- `output/`: Contains exported analysis results (`species_summary.csv`, `filtered_iris.csv`).
- `src/`: Directory for source scripts.
- `iris_analysis.ipynb`: Main Jupyter Notebook with complete data analysis.
- `pyproject.toml` & `uv.lock`: Project dependency specifications.

## Key Findings
1. Dataset contains 150 rows and 5 columns with no missing values.
2. Three distinct species: setosa, versicolor, and virginica (50 samples each).
3. `virginica` has the highest average petal length.

## Setup Instructions
1. Install dependencies using `uv`: `uv sync`
2. Run notebook using Jupyter Notebook or Google Colab.
